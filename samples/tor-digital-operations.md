# Digital Operations Workspace — sample TOR
Customer: Nusantara Logistics
The customer needs a single operations workspace for service requests and delivery tracking.
The solution must integrate existing ERP records through authenticated REST APIs.
The team needs React views with role-based approval and an auditable action history.
Python integration must validate incoming records before committing business state.
Timeline: phased discovery and pilot; exact dates to be agreed at kickoff.
Integration: customer ERP REST API; sandbox and API owner required before pilot.
Acceptance: approved requirement matrix, successful end-to-end pilot, and signed test evidence.
Budget: commercial envelope to be validated by Sales; no rate card supplied in this sample.
